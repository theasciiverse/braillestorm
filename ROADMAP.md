# Roadmap

What each release up to 1.0.0 brings. Versions follow the Asciiverse rule:
0.x.0 while playable but unfinished, 1.0.0 when everything planned is in.
From 0.4.0 on this is a proposal (2026-10-29), not settled yet.

## 0.2.0: built

- The ship, the warping grid, bombs, three enemy kinds (glob, cursor, fork)
- Waves with banners, the clear bonus, rushes from wave 10
- Lives, extra lives, game over, high score, the demo autopilot

## 0.3.0: built

- Sound, all synthesised
- A score multiplier up to x10
- Two more enemy kinds: the spinner and the null

## 0.4.0: built

- Pick-ups now and then from enemies shot down, about one every half
  minute: W wide fire, R rapid fire, S a short shield, B an extra bomb
- Stages: every five waves the grid moves on to the next colour

## 0.5.0: built

- Two more enemy kinds: the zombie, whose body gets back up unless it is
  reaped, and the escape, which marks a spot by the ship and jumps there
- Music, synthesised: faster with the waves, fuller as the field fills, a
  key for each stage

## 1.0.0: built

- Everything above played through and tuned (David, 2026-10-29)

## 1.0.1: built

- [x] Gamepads work on Windows: gilrs reads them through XInput, since its
  default (Windows Gaming Input) only reports to a program with a focused
  window of its own, which a terminal game never has
